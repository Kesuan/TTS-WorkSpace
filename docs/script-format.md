# 对白脚本格式 v1

> 多角色对白脚本（有声书 / 广播剧 / 配音生产）的输入格式。解析器在 🚧 M1 实现；本文档为**格式契约**，实现与测试以本文档为准。

## 示例

```
# 第一章
## 雨夜

// 注释行（行首 //）
旁白: 站台的灯闪了两下。
阿岚: (低沉)[叹气] 又是这样的雨……
    他把伞往前递了递。
    雨点砸在伞面上，噼啪作响。
小满: 哥，你还在等那班车吗？
没有角色前缀的段落默认归入「旁白」。
```

## 语法规则

| 规则 | 说明 |
| --- | --- |
| 编码 | UTF-8（LF 或 CRLF 均可） |
| 角色行 | `角色名: 台词`；冒号兼容半角 `:` 与全角 `：` |
| 角色名 | ≤ 24 字符；不可包含 `:` `：` `[` `]` `/`；解析时去除首尾空白 |
| 续行 | 以**空白（空格 / Tab）开头**、且紧跟台词行（中间无空行）的非角色行 —— 追加到上一条台词；中文默认无连接符，英文可用 `--join-with-space` |
| 章节 | `# 标题`（可选，用于分组与导出目录） |
| 场景 | `## 标题`（可选，同上） |
| 其他标题 | `###` 及以上视为注释，忽略 |
| 注释 | 行首（去空白后）为 `//` 的整行；行内 `//` 不处理（避免误伤 URL） |
| 空行 | 结束当前续行（续行必须紧跟台词行）；本身不产生条目 |
| 行内标签 | `(风格)`（通常置于台词开头）与 `[音频标签]`（任意位置）**原样保留**，直接透传给 MiMo API |
| 旁白 | `旁白:` 显式写法；未缩进且无角色前缀的段落默认归入「旁白」（`--no-narrator-fallback` 可关闭，届时忽略并告警 `W_TEXT_IGNORED`） |
| 行数上限 | 无硬限制；建议单文件 ≤ 1MB |

### 角色行判定与校验

- 冒号取**第一个** `:` 或 `：`；前缀（去空白）即角色名。
- 角色名不可含 `[` `]` `/`；包含这些字符的行**不视为角色行**（按普通文本处理，通常是误用标签或路径）。
- 冒号后紧跟 `/` 的行不视为角色行（避免 `https://…` 被误判为角色 `https`）。
- 角色名超过 **24 字符** → 解析失败：`E_PARSE_SCRIPT`（退出码 1），`error.details` 含 `{file, line, col, role}`。
- 缩进行若没有可续接的台词 → 告警 `W_ORPHAN_CONTINUATION`（行号在告警中）。

## 稳定行 ID

行 ID 由内容派生，保证“重导入不炸、改动可追踪”：

```
id = "L" + sha256(章节 | 场景 | 角色 | 规范化文本)[0:8]
```

- 规范化文本：去除首尾空白、合并连续空白（行内标签保留原样）。
- 同文本重复行（同一章节+场景+角色下）：追加序号后缀 `-2`、`-3`。
- **文本改动的行**：与旧行处于同一位置（章节 / 场景 / 角色 / 序号相同）时计为 `changed` —— 行级覆盖迁移到新行，旧行标记 `removed`（保留 takes 作历史），新行回到 `pending`（需重新生成）。
- 其余情况按内容判断：新内容为新行（`added`）；脚本中消失的行标记 `removed`，其 takes **保留不删除**（导出默认排除）。
- 重导入输出 diff：`added` / `removed` / `changed` / `unchanged`。

## 行级参数覆盖（非脚本语法）

需要给单行指定不同音色 / 风格时，**不要**改脚本语法，而是写入 `lines.json`（`tts line set`，🚧 M1）：

```bash
tts line set --line L3f2a9c01 --style "(低语) 我没事，真的。"
```

原则：脚本保持“可读的创作文本”，工程参数走项目元数据（可回滚、可审计、Agent 可控）。

## 解析报告（`tts project import --json`）

```json
{
  "ok": true,
  "data": {
    "script": "script/chapter1.txt",
    "counts": { "lines": 42, "roles": 3, "chapters": 1, "scenes": 2, "narrator_lines": 5 },
    "roles": ["阿岚", "小满", "旁白"],
    "unbound_roles": ["小满"],
    "warnings": [
      { "line": 7, "code": "W_ORPHAN_CONTINUATION", "message": "缩进行没有可续接的台词，已忽略" }
    ],
    "diff": { "added": 42, "removed": 0, "changed": 0, "unchanged": 0 }
  }
}
```

- 告警码：`W_ORPHAN_CONTINUATION`（孤儿续行）· `W_TEXT_IGNORED`（旁白回退关闭后忽略的段落）。
- `unbound_roles`：尚未绑定音色的角色（批量生成前必须先绑定，`tts role bind`）。
- 解析失败（角色名超长 / 文件缺失等）返回 `E_PARSE_SCRIPT` 或 `E_NOT_FOUND`（退出码 1）。
